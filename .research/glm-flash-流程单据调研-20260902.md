## ② Q1 流程闭环：项目入库→投决→设立→出资→投后→退出→清算

### 2.1 逐系统做法

**（1）eFront / FrontInvest**
- 以"另类资产全生命周期"为框架：募资→交易管道（deal flow/pipeline）→投资管理→基金运营（capital call/distribution）→组合监控→退出清算；数据按 Fund level / Portfolio company / Client level / Cash flow level 四层维度组织，模块可按需组合。来源：https://zhuanlan.zhihu.com/p/425940456
- 官方将 Deal Flow & Pipeline 定位为 front office（投资团队）与 back office（基金行政）的衔接模块。来源：https://www.efront.com/en/alternative-investment-solutions/pipeline-and-deal-flow-management
- 阶段状态机的具体节点枚举公开材料未见（未能核实）；业内反馈其"操作机械化、必须按特定步骤才能安全保存"，说明状态推进由固定动作驱动而非自由编辑。

**（2）PEPM（苏州梓川）——国内落地样本量最大**
- 博华资本案例明确披露直投全流程节点链：**保密协议 → 立项 → 尽职调查 → 投决 → 投资协议 → 交割（打款）→ 退出**，初筛与其他协议另配在线审批。来源：https://www.pepm.com.cn/p/customercase/
- 百度资本案例："项目管理：入库、立项、尽调、投决等项目全生命周期；基金管理：注册备案、定向募集、出资划款、披露、退出清算"——项目线与基金线两条状态链并行，靠流程串接。来源同上。
- 道禾长期投资案例披露单项目档案字段序列："基本概况→本轮次投资信息→工商信息→立项信息→尽调记录→投决信息→签约信息→出资记录→投后会信息"，并关联项目事件/走访/流程/现金流。来源同上。
- 海通开元案例：直投项目分**储备项目池 / 投前项目 / 投后项目**三段列表，通过"申请流程"推进项目跨段。来源同上。
- 农发产投案例（2025）：**项目入库申请流程通过后自动归集到项目总库及对应板块**；风险预警四类自动触发：收盘价触及预警线/平仓线、投后报告逾期未更新、定增解禁后未发起退出申请、退出后未发起项目总结报告。来源同上。——"跨阶段自动联动+超期自动提醒"最完整的公开描述。
- 新尚资本案例："项目模块新增二次立项、二次办公会、二次投决内容以及对应的二次流程"——投决被否后可走"二次流程"重新上会，而非一次否决即终结。来源同上。
- 放弃/淘汰项目的归档库与放弃原因树：公开案例未见对应描述（未能核实）。

**（3）蓝凌 VCPE（含华润资本 IMS 落地）**
- 基金管理"对基金**设立、决策、募集、投资、运营和清算**全环节电子化管理"；投资管理"从项目**立项到退出**全流程系统管理，建立项目池"；退出管理"系统自动统计每笔基金退出情况+退出核算平台"。来源：https://www.landray.com.cn/static-old/solution/vcpe/index.html
- 华润资本 IMS：面向投资人/被投企业/管理团队/投资经理/财务/合规风控/法务/管理员八类角色，上线投资人管理、基金募集、项目投资、财务管理、基金运营五大模块，**对投资项目各阶段以"项目工程模式"管理**（按阶段分解推进），基金设立走"基金创立流程"。来源：https://www.sohu.com/a/155170640_690258
- 华润资本支持"每只基金各自的投资团队接入和差异化管理流程"——阶段流程可按基金差异化配置。来源：https://www.landray.com.cn/static-old/solution/vcpe/index.html

**（4）VC800**

**（6）融都科技**

**小结（行业共识）**：
1. "投前管道（池）→已投（投后）→退出"三段分池 + 流程推进跨池是国产主流形态（PEPM/海通开元三池最典型）；
2. 基金线与项目线并行、在"出资/缴款"处汇合（VC800、Carta、融都均如此）；
3. 停滞处理以"定时器 + 自动提醒/自动动作"实现（简道云限时处理、明道云超时策略、农发产投四类预警）；
4. "放弃归档不可回流"在公开材料中无直接对应，最接近的是"回收站可恢复"（VC800/简道云）与"二次投决流程"（新尚资本）——本原型的"放弃后不可回流"属更严格的自有设计，可作为差异化保留。

## ③ Q2 单据流转：状态机、绑定互跳、驳回处理、审批链

### 3.1 单据状态机（完整画法）

- **REBUILD**（表述最简洁）：`草稿 → 审批中 → 通过 / 驳回 / 撤回`，驳回后可修改重提。来源：https://getrebuild.com/docs/admin/approval
- **织蝶云 OA**："我的申请"按 **审批中、同意、拒绝、驳回、撤回、草稿** 6 种状态筛选，驳回态可修改后重新提交。来源：https://www.zhidieyun.com/blog/how-to-manage-and-create-an-application-in-the-oa-approval-process-zhidieyun-oa-approval-management
- **金蝶云星空**（ERP 单据口径）：单据状态含 **暂存/保存/审核中/已审核/重新审核**；驳回后单据变更为"重新审核"、可修改再提交；"反审核"把已审核单据拉回可修改态；启用审批流的单据不允许直接删除。来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=顺签审批流程 ；https://www.kingdee.com/tag/1470588312308695042.html ；https://vip.kingdee.com/article/297868445403148544
- **金蝶 EAS**：多级审核中间态保持"提交"且不可修改，审批"不同意"则审核不成功退回。来源：https://vip.kingdee.com/eascloud/help/8.6/SCM.web/topics/noname1258.html
- **明道云**：审批结果四值 **通过/否决/撤回/中止**；建议自建状态字段（草稿/审批中/已通过/已否决）并配"节点通过后更新/否决后更新"回写。来源：https://help.mingdao.com/workflow/node-initiate-approval-flow/ ；https://help.mingdao.com/workflow/node-approve/
- **腾讯云审批中心**：撤回后可重新提交进入"审批中"；可查看审批人与进度。来源：https://www.tencentcloud.com/zh/document/product/1254/79058
- **推荐状态机（综合）**：`草稿 → 待审(审批中) → 通过 ｜ 驳回(→重提回待审) ｜ 撤回(→草稿) ｜ 否决(终态) ｜ 中止`；ERP 派另加"已审核 → 反审核 → 重新审核"的生效后回退环。

### 3.2 单据与业务对象的绑定与互跳

- 盈嘉资本（PEPM）："投资流程审批包括（**立项、投决、决策、交割、分配**等）"——审批单按业务节点类型挂在项目下。来源：https://www.pepm.com.cn/p/customercase/
- 博华资本： "**流程中心**：将所有（或部分）流程汇总显示，可筛选，并**直接跳转到该数据对应的流程中**"——单据↔业务对象双向互跳的集中入口。来源同上。
- 武岳峰科创："流程数据、文件自动归集到项目数据中"；中鑫致道："合同管理与协议审批流程集成，**根据流程表单内容自动生成合同主干信息**"——单据数据回写业务对象字段。来源同上。
- 海通开元：用印/协议签署流程审批结束后**生成用印编号并在用印台账归档**——单据审批完成即生成台账记录。来源同上。
- 农发产投："项目入库申请流程通过后将项目归集到项目总库""流程中上传的文档在审批结束后自动归集项目中"。来源同上。
- 简道云：流程表单（单据）即数据记录，以"关联数据/关联子表"字段绑定项目/基金主记录，流程结束后由智能助手回写主表状态。来源：https://hc.jiandaoyun.com/doc/12524
- 金蝶云星空：单据下推/上查（关联单据链）为标准互跳；审批驳回触发"反审核"把下游单据拉回。来源：https://zhuanlan.zhihu.com/p/1981773386683270710

### 3.3 驳回后：回滚还是带痕修改？

- **简道云（带痕派）**：回退"保存节点负责人对数据的更改"，被回退节点在"我的待办→回退"可见，流程动态保留审批意见，回退节点显示单独标识；支持"上一节点/指定范围节点"回退，重提时可选"按流程顺序审批 / 直达当前节点"。来源：https://hc.jiandaoyun.com/doc/12524
- **明道云（带痕派）**：退回可填意见并选择退回节点；重提支持"重新执行流程 / 直接返回审批节点（跳过中间）"；审批人暂存修改直接生效但在操作日志与表日志留痕；"否决/退回时无需填写表单字段"避免脏数据。来源：https://help.mingdao.com/workflow/node-approve/
- **金蝶（回滚派）**：驳回关联"反审核"，单据状态回滚为"重新审核"，已生效下游数据需先撤销；审批记录仍留痕。来源：https://help.open.kingdee.com/dokuwiki/doku.php?id=顺签审批流程
- **概念区分**：驳回=审批人否定结论；退回=已办环节重新办理；撤回=提交人收回；撤销=已生效结果失效，四者不可混用。来源：https://zhuanlan.zhihu.com/p/2072736361807982981
- **结论**：业务审批类单据（立项/投决）行业主流是**带痕修改**（数据不回滚、留审批日志与修改日志）；涉资金单据（付款/分配）ERP 派倾向**状态回滚+反审核**，防止带痕修改破坏财务一致性。

### 3.4 角色审批链设计

- 明道云最完整：审批人三种配置（**自定义固定/动态、按部门层级逐级审批、由上一审批节点选择**）；多人审批四种通过规则（**或签、会签全员通过、会签一人通过且否决需全员、按比例投票**——通过人数=成员数×比例向上取整，否决人数=成员数−通过人数+1）；支持转审、加签（审批前/通过后）、批量审批、邮件快速审批、意见模板、签名、密码验证、限时处理（超时自动通过/否决/中止）。来源：https://help.mingdao.com/workflow/node-approve/
- 简道云：常规审批/逐级审批/动态负责人（部门、成员字段作为负责人）、流程加签/转交/否决/暂存、批量审批、批量调整流程负责人。来源：https://hc.jiandaoyun.com/doc/12524
- 投决会场景实证（PEPM 案例页）：恒昌资本"多部门会签、多委员投票表决"；渝富基金系统"决策会议投票，自动记录决策过程数据，并生成决议签字文件"；农发产投"投资管理委员会、党总支会议、董事会、立项审批"多委员会流程并存。来源：https://www.pepm.com.cn/p/customercase/
- 泛微 e-cology：流程中心（待办/已办/抄送）+ 表单/路径分离配置；E10 支持"千人千面"流程列表与标题状态标记。来源：https://www.weaver.com.cn/e10/function/ ；https://www.hnweaver.com/Article/fwe10gzlch_1.html

## ⑤ 对本项目的可借鉴点

1. **六节点审批**：审批中心加"抄送我的"+催办（简道云四区，https://hc.jiandaoyun.com/doc/12524 ）；驳回语义分级——立项/投决"带痕退回+重提直达节点"（明道云/简道云），付款/收益分配"驳回即回滚重走"（金蝶反审核，https://help.open.kingdee.com/dokuwiki/doku.php?id=顺签审批流程 ）。
2. **十二阶段**：投决否决≠放弃——允许"二次投决"重上会（新尚资本，PEPM 案例），与"未投归档不可回流"双轨并行；阶段推进用流程驱动状态（德联 JS 联动实证）。
3. **停滞提醒**：30 天未推进=农发产投式"超期未动作自动预警"，可加超时升级上级（明道云超时策略）。
4. **资料包六类**：审批单附件/结论审批结束自动归集对应材料包（武岳峰/农发实证）。
5. **LP 认缴/实缴**：参照 VC800"基金→LP出资/LP分配"页签，认缴/实缴两栏进度+出资进度字段（长兴基金）。
6. **退出三段**：退出批次→分配单→清算五步，对应渝富"决策→分配测算→一键导出结项复盘"链路（PEPM 案例）。
7. **8 组菜单 18 页**：维持对象域 IA，统计报表内分"驾驶舱/业务报表"两级；详情页不进菜单符合行业惯例。
