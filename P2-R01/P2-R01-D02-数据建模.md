## 一、建模约定

| # | 约定 | 说明 |
|---|---|---|
| 1 | 命名 | 表/字段 snake_case；表名单数英文（project、fund…） |
| 2 | 主键 | `id BIGINT` 自增；对外展示用业务编号（如 `project_no`） |
| 3 | 审计字段 | 所有业务表含 `created_at / created_by / updated_at / updated_by` |
| 4 | 软删除 | `deleted_at`（可空）；放弃/注销类终态数据不物理删除（合规留痕） |
| 5 | 枚举 | 状态类字段用 VARCHAR + 字典表/枚举值约束（便于业务后续加减） |
| 6 | 时间 | `DATETIME`，存本地时间（单机构使用，不做多时区） |
| 7 | 附件 | 文件元数据表统一管理，业务表以 FK 引用；文件本体存对象存储/磁盘，路径入库 |
| 8 | 基金-项目关联 | fund ↔ project 用关联表 `fund_project` 表达，**1:N**（一支基金多项目；09-15 评审 Q1 定案，原 1:1 唯一约束废止） |
| 9 | 字典引用 | **业务表存字典 key 不存显示名**（09-15 评审 Q15），显示名经字典解析；停用项显示带标记、不过滤（Q14） |

## 三、实体字段表

### 3.1 project 项目档案（功能点 #1/#2）

| 字段 | 类型 | 说明 |
|---|---|---|
| id / project_no | BIGINT / VARCHAR | 主键 / 业务编号（如 PRJ-2026-0001） |
| name | VARCHAR(200) | 项目/企业名称 |
| industry | VARCHAR | 行业赛道（字典） |
| round | VARCHAR | 轮次（字典：天使/A/B/…/定增/私有化退市） |
| source_channel | VARCHAR | 来源渠道（谁介绍/主动接洽） |
| contacts | VARCHAR | 对方联系人（姓名/职务/电话，文字） |
| status | VARCHAR | 当前状态（10 标签 + 放弃/退出态，见 P2-R01-D01） |
| current_stage | TINYINT | 当前阶段号 1~12（0=未投归档） |
| valuation / intend_amount | DECIMAL | 拟投估值 / 拟投金额（行业标准字段，Q4） |
| fund_id | BIGINT | 冗余基金 ID（源自 fund_project，列表加速） |
| owner | BIGINT | 负责人（FK sys_user）——**owner 数据权限**：谁负责谁可见/可办（09-15 评审 Q26） |
| abandoned_at | DATETIME | 放弃时间（未放弃为空） |
| remark | TEXT | 备注 |
| + 审计/软删除 | — | 约定字段 |

### 3.2 stage_transition 阶段流转记录（#3/#4）

| 字段 | 类型 | 说明 |
|---|---|---|
| project_id | BIGINT | FK |
| from_stage / to_stage | TINYINT | 1~12 |
| path_type | VARCHAR | ④ 双路径：A 直接资料包 / B 先访谈再资料包（仅 to_stage=4 时记录） |
| occurred_at | DATETIME | **发生时间（业务时间，可补录）** |
| operator | VARCHAR | 操作人 |
| meeting_minute_id | BIGINT | 关联会议纪要（立项会/投决会，可空 → #8） |
| stagnant_days（派生） | INT | **停滞提醒（08-27 新增，功能点 18）**：当前阶段停留超阈值天数（默认 30，系统配置）标记停滞并推送消息中心；③ 保密协议为典型（对方同时对接多家资金方故意拖延）；**停滞 ≠ 放弃**，项目仍留管道 |

### 3.3 abandon_record 放弃记录（#5 核心差异化）

| 字段 | 类型 | 说明 |
|---|---|---|
| project_id | BIGINT | FK，1:1（一项目至多一条） |
| abandon_stage | TINYINT | 放弃时所处阶段：①②④⑤⑥⑦（③无放弃点，规则约束）；⑦ 含投决前主动撤回与投决否决两个子场景 |
| subject | TINYINT | **放弃主体（08-27 两级原因树一级）**：1=GP放弃（投决前管理人主动，①~⑦）/ 2=LP放弃（⑦ 投决会否决）；按 abandon_stage + 场景自动判定 |
| reason_id | BIGINT | FK → abandon_reason（二级叶子，按 subject 过滤） |
| reason_custom | VARCHAR | 自定义补充（Q5；叶子原因两级结构见 3.4：主体预置 × 叶子预置 + 自定义） |
| detail | TEXT | 备注说明 |
| occurred_at | DATETIME | 放弃时间（自动带出，可改） |

### 3.4 abandon_reason 放弃原因字典（#6 核心差异化）

| 字段 | 类型 | 说明 |
|---|---|---|
| subject | TINYINT | **一级：放弃主体**（08-27 两级原因树）：1=GP放弃 / 2=LP放弃——两类业务逻辑不同（管理侧筛选 vs 出资侧决策），统计/复盘/责任判断分开 |
| stage_scope | TINYINT | 适用放弃节点（仅 subject=GP：①②④⑤⑥⑦，④ 含访谈/资料两个子场景可拆两行；LP 固定 ⑦ 投决否决） |
| category | VARCHAR | 二级分组（GP 按节点场景：超范围/团队/财务/估值条款/投资人未出资…；LP：行业/赛道/风险/估值/政策合规…） |
| label | VARCHAR | 叶子原因展示文案（GP 初版见 P2-R01-D01 1.2；LP 初版：不看好行业、不看好赛道、项目风险异议、估值异议、政策/合规顾虑——待业务补充） |
| sort_no / enabled | INT/BOOL | 排序/启停 |

### 3.5 fund 基金（#17，Q7：20+ 只、1:1 基准）

| 字段 | 类型 | 说明 |
|---|---|---|
| id / fund_no | BIGINT / VARCHAR | 主键 / 业务编号 |
| full_name | VARCHAR(300) | 有限合伙全称 |
| registered_capital | DECIMAL | 注册资本 |
| established_date | DATE | 成立日期 |
| registered_place | VARCHAR | 注册地（境内/境外标记，20+ 只含境外） |
| currency | VARCHAR | 币种（默认 CNY，境外基金 USD；金额字段随主体币种，09-15 评审 Q4） |
| status | VARCHAR | 存续中/已注销（清算后） |
| lpa_files / registry_files | FK | LPA 协议、工商注册文件（逻辑包"基金设立文件"） |
| remark | TEXT | 备注 |

### 3.6 fund_project 基金-项目关联（1:N，09-15 评审 Q1 定案）

| 字段 | 类型 | 说明 |
|---|---|---|
| fund_id / project_id | BIGINT | 双 FK |
| — | 关联口径 | **1:N**（一支基金可投向多个项目；09-15 评审 Q1 定案，原「每 fund_id 至多一条」唯一约束废止） |

### 3.7 lp_entity LP 主体 + lp_investment 出资（#20，Q11 极简）

> 极简口径：**文字录入、非强校验主数据**；一 LP（自然人/机构）可有多个出资主体。

| 实体 | 字段 | 类型 | 说明 |
|---|---|---|---|
| lp_entity | lp_name | VARCHAR | LP 姓名/机构名（归组键） |
| lp_entity | entity_name | VARCHAR | 出资主体名称（一 LP 多主体） |
| lp_entity | qualification_files | FK | 资质材料：LPA/主管协议/募集协议（上传归档） |
| lp_entity | qualified_at / qualified_by | — | LP 资格认定（设立基金出资前完成） |
| lp_entity | qualified_valid_months | INT | 认定有效期（月），默认 24、自认定通过日起算（09-15 评审 Q6，数值可调）；认定走审批流（Q5，审批类型=认定审批） |
| lp_investment | fund_id / lp_entity_id | BIGINT | FK |
| lp_investment | subscribed_amount | DECIMAL | 认缴金额（文字录入转数值，如 1000 万） |
| lp_investment | paid_amount | DECIMAL | 实缴金额 |
| lp_investment | invested_at | DATE | 出资时间 |
| lp_investment | ratio | DECIMAL | 约定分配比例（收益分配核算用） |

### 3.8 material_package 材料逻辑包 + material_file（#7，08-26 强制分类）

| 实体 | 字段 | 说明 |
|---|---|---|
| material_package | project_id | FK |
| material_package | pkg_type | **六类枚举**：BP包/路演纪要/尽调资料包/投决包/基金设立文件/投后资料 |
| material_file | package_id / file_name / file_path / file_size / uploaded_by / uploaded_at | 文件元数据 |

> 治现有 CRM 痛点：上传时**必须选择逻辑包**，不允许"通用附件堆砌"；已投项目另挂基金设立文件（LP 协议/工商/托管协议/证券户凭证）。

### 3.9 post_event 投后事件（#10）

| 字段 | 说明 |
|---|---|
| project_id | FK |
| event_type | 股东会决议/董事会决议/重大经营变动/定期访谈纪要/其它（不强制细分，08-26 口径） |
| title / content | 标题/内容 |
| occurred_at | 事件时间（时间戳固化） |
| files | 附件 FK（决议扫描件等） |

### 3.10 post_report 投后报告（#11）

| 字段 | 说明 |
|---|---|
| project_id / period | FK / 报告期（2026Q1、2026 年报） |
| report_type | 季报/年报/专项报告（上市减持、清算报告等） |
| file_id | 手动上传（**不做自动收集**，08-26） |
| uploaded_at / uploaded_by | 上传留痕 |

### 3.11 alert_rule 到期提醒规则（#16，前置 ≥30 天）

| 字段 | 说明 |
|---|---|
| project_id / fund_id | FK |
| rule_type | 对赌协议到期/回购触发/关键条款履约/资质续期 |
| due_date | 到期日 |
| advance_days | 前置提醒天数，**默认 30，只可调大** |
| notify_to | 提醒对象（角色/用户） |
| status | 未提醒/已提醒 |

### 3.12 risk_alert 风险预警记录（#14）

| 字段 | 说明 |
|---|---|
| project_id | FK（已投项目） |
| alert_type | 股价异动/舆情 |
| source | 数据源：系统采集/企查查/同花顺（对接为候选） |
| content / url | 预警内容与原文链接 |
| occurred_at / pushed_at | 发生时间/推送时间（指定网站定时收集·定期推送） |

### 3.13 exit_batch 项目退出批次（#18，三段第一段）

| 字段 | 说明 |
|---|---|
| project_id / batch_no | FK / 批次号 |
| exit_type | 分红/股权转让/IPO 减持（表单选择） |
| price / quantity | 卖出价格/数量 |
| occurred_at | 时间节点 |
| principal / income / roi | 退出本金/收益/收益率（自动核算） |
| status | **批次状态机（09-15 评审 Q21）**：待执行/执行中/已完成/已取消；取消与展期为行内留痕操作、不走审批；IPO 减持登记强制合规复核 3 勾选＋复核人（Q7） |

### 3.14 distribution_item 收益分配明细（#19，三段第二段）

| 字段 | 说明 |
|---|---|
| exit_batch_id | FK（承接该批退出资金） |
| lp_entity_id | FK（按 LP 约定比例核算） |
| amount / ratio | 分配金额/比例 |
| distributed_at / paid_at | 分配时间节点/付款时间 |
| payment_proof | 付款记录附件（★触发审批⑤分配） |

### 3.15 liquidation 清算注销（#17，三段第三段）

| 字段 | 说明 |
