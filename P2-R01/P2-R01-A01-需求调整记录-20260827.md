## 会议要点摘录

- **⑧⑨顺序**（王总）："出资是要打到一个公司基金注册了之后才有账户，款才能打过去"——先设立后出资；道远已向胡博复核确认。
- **GP/LP 逻辑**（王总）：GP 是管理人、LP 是出资人；投决前放弃是 GP 基于项目判断的主动放弃，投决未通过是 LP 对行业/项目不认可的否决——"这两个一定要有区分"。
- **保密协议拖延**（王总）：融资企业可能一边保持沟通一边对接其他资金方，签署长期耗着——节点打问号，补充"耗时很长、长期未进入下一阶段怎么办"。
- **原型**（王总）：做最基本但能跑起来的 BS 版流程，打开网页处理真实数据，BP 资料真实存储，不是静态 HTML。
- **知识库衔接**（王总）：文件存储要为后续知识库管理预留（分类方式、目录树、元数据表）——经道远评估：本期经 MCP server 后置处理。
