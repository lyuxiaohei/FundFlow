系统类型架构对比：轻量管道派 / 全流程派 / 投资部需求

方案A 轻量管道派 / 方案B 全流程派 / 方案C 投资部需求，三线按「募 · 投 · 管 · 退 · 支撑」段位对齐，箭头表示段位自上而下流转（募→投→管→退）；同类功能同背景色（紫=募、蓝=管道/投、橙=投后、红=清算/退、灰=统计/支撑），绿色为投资部独有的不投原因分类记录（同类产品均缺失，绿色箭头=放弃分支），虚线框为缺失/待确认段（文字置灰、保留段位底色），虚线短接为支撑层挂接。

方案 A · CRM

轻量管道派

  • 仅覆盖「投」段与支撑层，轻量、快捷、自动化
  • 募 / 管 / 退 三段缺失（图中虚线占位）
  • 契合度：Affinity 中低 / 4Degrees 低

方案 B · F2B

全流程派

  • 募投管退 + 支撑五段全覆盖
  • 重实施、机构级采购
  • 契合度 Top：蓝凌（高）· 璞华（高）

方案 C · 本项目需求

投资部需求 = 组合 + 空白

  • 「投」段取 CRM 派形态，「管 / 退」段取全流程派能力
  • 放弃路径在投段分叉直达不投原因记录（绿色箭头）——同类产品均缺失，自建差异化亮点
  • 「募」段极简确认（08-26）：LP 文字录入 + 资格认定 + 材料上传，无募集流程/IR；整体最接近蓝凌/璞华（约 75~80%）
